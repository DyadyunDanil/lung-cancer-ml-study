# H2 — сценарии механизма формирования риска

## Назначение

Проверить, как качество PLCOm2012, Logistic Regression, Random Forest, XGBoost и MLP зависит от того, какую известную функцию `P(Y=1|X)` мы использовали для синтетических исходов. Во всех сценариях распределение исходных 11 признаков `P(X)` одинаково.

**Это контролируемый модельный эксперимент, не перенос клинических коэффициентов между популяциями.** Опубликованные компоненты используются как исходные математические конструкции; дополнительные решения перечислены ниже. Источники с точными заимствованиями: `references/literature.md`.

## Общая часть

`L0(X)` — логит опубликованной PLCOm2012; `d` — годы курения, `c>0` — сигареты/сутки, `q` — годы после отказа, `s=1` — текущий курильщик.

Для любого сценария: `P(Y=1|X) = sigmoid(L_scenario(X))`.

Исходные компоненты PLCOm2012:

```text
D0(d) = 0.0317321 * (d - 27)
C0(c) = -1.822606 * ((c / 10)^(-1) - 0.4021541613)
Q0(q) = -0.0308572 * (q - 10)
```

Индикатор текущего курения `0.2597431*s` сохраняется во всех сценариях.

## S0: PLCOm2012

`L_S0 = L0`. Никаких изменений в истинной функции.

## S1: совместная модель стажа и интенсивности (Remen, 2018)

В мужской подгруппе Table 4, model 5, авторы оценивают **в одной модели** два коэффициента: `0.072 * d` и `0.64 * ln(c)`.

```text
L_S1 = L0 - D0(d) - C0(c) + 0.072*d + 0.64*ln(c) + alpha_S1
```

Член времени после отказа `Q0(q)` остаётся из PLCO. Формула — гибрид, а **не полная модель Remen**. В исследовании Remen эти коэффициенты оценены в рамках модели отношения шансов случай–контроль с дополнительными ковариатами.

## S2: Comprehensive Smoking Index (CSI; Remen, 2018)

Публикация задаёт (для мужчин) параметр `tau=26 лет`, лаг `delta=1 год` и коэффициент `1.31 * CSI` (Table 4, model 4).

```text
q_star = max(q - 1, 0)
d_star = max(d + q - 1, 0) - q_star
CSI = (1 - 0.5^(d_star / 26)) * 0.5^(q_star / 26) * ln(c + 1)
L_S2 = L0 - D0(d) - C0(c) - Q0(q) + 1.31*CSI + alpha_S2
```

Исходный индикатор текущего курения оставлен, а три компонента курительной истории заменены целиком: **нет двойного учёта**. Это также гибрид PLCO и отдельного опубликованного компонента Remen, не репликация целой модели.

## S3: моделируемые взаимодействия (параметры симуляции)

Взаимодействия мотивированы исследованием SYNERGY (Vlaanderen et al., 2014); **конкретные формы и коэффициенты ниже выбраны нами**, не оценены авторами SYNERGY:

```text
I1 = ((d - 27) / 10) * ln((c + 1) / 11)
I2 = (1 - s) * ln((c + 1) / 11) * ((q - 10) / 10)
L_S3 = L0 - 0.18*I1 - 0.15*I2 + alpha_S3
```

Смысл: взаимодействие стажа и интенсивности и модификация эффекта времени после отказа интенсивностью (только у бывших курильщиков). Знаки/величины выбраны для сценария и не отражают клинически оценённые коэффициенты.

## Интерсепт и воспроизводимость

Для `S1–S3` константа `alpha_s` находится численно так, чтобы средняя **истинная** вероятность на созданном синтетическом пуле `X` была равна средней вероятности S0. Это **наше методологическое решение**, позволяющее уменьшить различия по доле положительного класса. Оно не гарантирует одинаковые наблюдаемые числа `y=1` и не делает гибридные модели клинически откалиброванными.

Генерируем исходы при одинаковой последовательности независимых `U~Uniform(0,1)` для всех сценариев: `y_s=1[U<p_s(X)]`. Это снижает шум парных сравнений. Генерация и калибровка производятся **до разбиения** и не зависят от наблюдаемых тестовых меток. Обучаемые модели получают только 11 столбцов `FEATURE_COLUMNS`; `risk`, `delta_logit`, `calibration_shift` и прочие переменные механизма генерации исключены.

## Протокол оценки

- Один и тот же пул пациентов, одни и те же индексы train/validation/test во всех сценариях.
- Стратификация разбиения по S0; в S1–S3 частота классов в частях может несколько различаться.
- В каждой комбинации модель × сценарий подбор параметров через 3-fold CV только по train (pAUC при FPR≤0.10).
- На validation выбираем порог при Specificity≥90%, test оцениваем однократно.
- Смотрим pAUC, Recall/Specificity, ROC AUC, AP, Brier, а также MSE относительно известной истинной вероятности.
- Выигрыш на одном test — **не** универсальная победа алгоритма. В H4 потребуется повторение на независимых генерациях.

Допущения, которые требуют отдельной проверки в будущем: правдоподобность `P(X)`, применимость мужских коэффициентов Remen к синтетической популяции без метки пола, сопоставимость шкал case-control OR и шестилетнего абсолютного риска, чувствительность к силе эффектов S3.
