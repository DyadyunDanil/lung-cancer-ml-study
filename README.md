# Lung Cancer Risk Prediction: ML Study

Исследование качества и устойчивости моделей машинного
обучения для прогнозирования риска рака лёгких
на синтетических данных.

## Цель

Исследовать влияние настройки моделей и структуры
синтетических данных на качество прогнозирования
при заданном уровне специфичности.

## План исследования

1. Проверка и разработка генератора данных.
2. Сравнение базовых моделей.
3. Подбор гиперпараметров.
4. Исследование нелинейных зависимостей.
5. Проверка устойчивости результатов.
6. Интерпретация и практические выводы.

## Статус
Разработка и валидация генератора данных.
